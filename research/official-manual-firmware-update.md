# Официальная процедура «Manual robot firmware update» (Neato support, архив)

Источник: web.archive.org снапшот от 2025-11-29 (07:45:16) статьи
`support.neatorobotics.com/support/solutions/articles/204000055841-manual-robot-firmware-update`
(изучено лично оператором и мной 2026-09-17; сама статья и служебные API support.neatorobotics.com
блокируются встроенным браузером/WebFetch напрямую — прочитано через `web.archive.org`).

## Применимость и версия

**Robots: D800 | D8 | D9 | D10** — дословно, наши точные устройства (D800/D8/D9/D10 = Gen4).
App: MyNeato. Последняя прошивка на момент снимка: **`1.7.0-2933`** — СОВПАДАЕТ с версией, снятой у
нашего D9 через GATT (`Device Info`, `research/ble-vector.md`) и с версией из reddit-поста про recovery
mode D8. Подтверждает: это единая, актуальная (на конец 2025) прошивка всей линейки Gen4.

## Процедура (Windows и macOS идентичны по сути)

1. Установить/обновить приложение **MyNeato** (версия ≥1.5.11) — нужно **только чтобы проверить версию**,
   сама передача файла идёт БЕЗ приложения.
2. Скачать файл прошивки по прямой ссылке (см. ниже).
3. Робот на базе заряда, вынуть пылесборник.
4. У левого угла робота — **порт USB-C**.
5. Подключить USB-C к компьютеру. В проводнике/Finder появляется **«Neato Robot»** (как флешка/MTP-устройство).
6. Внутри — папка **«SW Update»**, в ней файл **«version»** (текущая версия, только для чтения).
7. Перетащить скачанный файл прошивки В ЭТУ ЖЕ папку «SW Update».
8. Копирование 5–10 минут, светодиоды **пульсируют жёлтым** — индикатор корректного процесса.
9. По завершении копирования робот **сам себя обновляет и перезагружается**: светодиоды мигают разными
   цветами, затем **музыкальный перезвон** — сигнал завершения.
10. Отключить USB-C, вернуть пылесборник.

**Это ТОЧНО совпадает по механике** с reddit-находкой (`community-vacuula-server.md`): устройство `Neato
Robot`, папка `SW Update`, поведение «не обычная флешка, ждёт официальный пакет». Официальная статья
подтверждает: SW Update-режим — штатный механизм, не найденный хакерами баг.

## Прямая ссылка на файл прошивки (найдена в HTML архивной страницы, href, не в видимом тексте)

```
https://neatorobotics-firmware-recovery.s3.us-east-1.amazonaws.com/Gen2/Neato_1.7.0-2933.swu
```

Формат `.swu` (software update container). Бакет назван `neatorobotics-firmware-recovery`, путь `Gen2/`
(внутреннее название линейки в самой компании — не путать с нашей нумерацией «Gen4»).

**Проверка доступности (2026-09-17):** прямой `curl` (в т.ч. с Referer/UA) → **`403 AccessDenied`** (XML
AmazonS3). НО через **Chrome оператора** (его сессия/регион) файл **СКАЧАЛСЯ** — значит бакет отдаёт не всем
(гео/сессия/политика), голый серверный запрос закрыт. Файл сохранён локально:
`<downloads>/Neato_1.7.0-2933.swu` (сам образ не публикуется — проприетарный, в .gitignore).

## Разбор скачанного файла (2026-09-17)

| Свойство | Значение |
|---|---|
| Размер | 165 420 576 байт (~157.8 МБ) |
| SHA-256 | `ba17120082e173f38824a43831ca8998a83f8901ebd4419ecba3786d7fae28d7` |
| Тип (`file`) | openssl enc'd data with salted password |
| Сигнатура (байты 0-7) | `Salted__` (`53 61 6c 74 65 64 5f 5f`) |
| Соль (байты 8-15) | `1eacf67ef2432bc5` |
| Тело после 16-байт заголовка | 165 420 560 байт, **кратно 16** (блок AES-CBC) |

**Файл ПОЛНОСТЬЮ зашифрован** — контейнер OpenSSL `enc` (ключ производный от пароля+соли через
EVP_BytesToKey). Доказательства: ноль ASCII-строк (`strings -n 6`) во всём 165 МБ; хвост высокоэнтропийный;
никаких открытых заголовков/секций/подписи снаружи. Это НЕ SWUpdate/CPIO/tar в открытом виде — монолитный
зашифрованный блоб.

**Ключа в файле нет.** Тривиальные статичные пароли не подошли: проверены `neato/Neato/NEATO/botvac/vorwerk/
neatorobotics/1.7.0-2933/neato2933/SW_Update/swupdate` × KDF `md5` и `sha256`, AES-256-CBC → ни один не дал
валидный magic (gzip/bzip2/squashfs/cpio/ELF/dtb/uImage/xz). Brute-force AES-256 нереален.

**Вывод:** содержимое прошивки (rootfs, ядро, бинарники) БЕЗ ключа не извлечь. Ключ дешифровки живёт НА
роботе (он расшифровывает `.swu` при drag-and-drop своим зашитым ключом) — извлечение = вскрытие + обход
secure boot (оператор вскрывать не готов). Это и есть «secure» природа Gen4: даже имея официальный файл,
его нельзя ни прочитать, ни подделать без ключа устройства.

## Что это даёт практически

1. **Для ВОССТАНОВЛЕНИЯ (recovery) ключ НЕ нужен.** Робот сам расшифрует файл — его можно применить как есть
   через штатный drag-and-drop в папку `SW Update`. То есть сохранённый `.swu` = «золотой образ» на случай
   окирпичивания (переустановить ту же 1.7.0-2933). Файл хранить как есть (зашифрованным).
2. **Для АНАЛИЗА содержимого — тупик без ключа.** Пути к ключу (все неинвазивные, кроме вскрытия):
   (а) MyNeato APK — проверить, не участвует ли приложение в дешифровке (низкая вероятность: drag-and-drop
   идёт мимо приложения; была отдельная статья про Android-путь обновления); (б) сообщество vacuula/brainslug
   («responsible disclosure, security implications» — вероятно, они знают механизм; оператор — участник Discord);
   (в) извлечение с робота (вскрытие + secure boot — отпадает).

## Уточнения сообщества vacuula (закреплённый гайд #gen4-rainbow, taxilof 29.06.2026) — ВАЖНЕЕ офиц. статьи

Прочитано через Chrome оператора 2026-09-17. Это проверенная сообществом версия процедуры:

- **Лечит именно проблему «please download neato app»** = НЕАКТИВИРОВАННЫЙ робот (случай нового D8 оператора и
  Bxlieve с D9). taxilof дословно: «This could work especially on "please download neato app" issue».
- **Условие применимости:** робот при подключении USB-C ДОЛЖЕН показываться как **MTP-устройство** (как
  USB-накопитель) на Windows/Linux. Если показывается — recovery официальной прошивкой возможен. Если робот в
  глубоком rainbow и Windows видит `USB\VID_0525&PID_A4A5` «USB download gadget» без диска (случай Youssef) —
  этот путь НЕ работает, ждать vacuula server (Philip2809).
- **MyNeato app НЕ нужен** — «Skip the download the MyNeato app — its useless». Прошивка заливается без него
  (официальная статья требовала app ≥1.5.11 — по опыту сообщества это лишнее).
- **Размер файла-эталон: 157.8 MiB / 165.46 MB.** Наш файл 165 420 576 байт = ровно 157.8 MiB — ПРАВИЛЬНЫЙ.
  «1 MB — неправильный файл с archive.org» (маленький архивный html, не прошивка).
- **Время: 20 минут и дольше** (не 5-10 из офиц. статьи). Все LED мигают жёлтым во время процесса. По
  завершении — 4 LED разом загораются зелёным, затем перезагрузка, затем ~2 мин «устаканивания» (робот СНОВА
  делает радужный LED — это нормально, само прекратится). **НИЧЕГО НЕ ПРЕРЫВАТЬ**, робот на базе на зарядке.
- Вариант-«сброс» (Dorikumi, #gen4): если просто заливка не помогает — можно удалить `version.txt` из папки
  `SW Update` и «обновить» на ту же прошивку — тогда это работает как сброс. Базово version.txt не трогать.
- **Побочный эффект (Dorikumi/sth281):** после переустановки ПО робот не может скачать карту (error 3004 —
  карта хранилась в облаке). Базовая уборка работает; карты/зоны — только когда выйдет vacuula server.

## ИТОГОВАЯ МЕТОДИКА (моя операционная процедура — «запомни, будешь делать»)

Применяется к неактивированному / требующему настройки Gen4 (D800/D8/D9/D10), если робот виден как MTP:
1. Робот на базе, на зарядке. Вынуть пылесборник. USB-C (порт у левого угла) → ПК.
2. В проводнике появляется «Neato Robot» → папка `SW Update` (внутри `version.txt` — текущая версия).
3. Перетащить `Neato_1.7.0-2933.swu` (157.8 MiB, SHA-256 `ba171200…fae28d7`) в папку `SW Update`.
   (Если не поможет — удалить `version.txt` и повторить = сброс.)
4. Ждать 20+ мин, все LED жёлтые. Не прерывать, не отключать USB.
5. 4 LED разом зелёные → перезагрузка → ~2 мин, возможен радужный LED (норма, пройдёт).
6. Готово. MyNeato app не нужен. Карта/зоны не восстановятся до vacuula server (error 3004 — ожидаемо).

Перетаскивание файла в `SW Update` могу выполнить я, когда робот подключён и смонтирован как диск.

## Решение оператора (2026-09-17)

Анализ содержимого (поиск ключа дешифровки) **остановлен** — не критичен. Файл оставлен **как
recovery-образ** для оживления окирпиченного Gen4 через штатный drag-and-drop (ключ для применения не нужен —
робот дешифрует сам). Ждём vacuula server как основной путь к управлению. Пути к ключу (Discord vacuula /
MyNeato APK) — в резерве, не задействованы.

⚠ **Сохранность:** образ незаменим (S3 отдаёт 403 всем, кроме браузера оператора; может исчезнуть). Держать
надёжную копию вне `Downloads`. Сверка — по SHA-256 выше.

## Хранение / право

Файл — **проприетарная прошивка Vorwerk/Neato**. НЕ публиковать, НЕ пушить, НЕ класть в git
(`*.swu`/`*.bin`/`*.img` в `.gitignore`). Держать локально как recovery-образ. SHA-256 выше — для сверки
целостности.

## Значение для проекта

1. **Подтверждает: SW Update — официальный, а не хакерский путь.** Это снижает риск для любого, кто решит
   исследовать USB-C recovery-режим (то, что нашёл reddit-пользователь) — устройство ведёт себя штатно.
2. **Если бы файл скачался** — это была бы официальная, подписанная прошивка, применимая через штатный
   drag-and-drop БЕЗ облака и без vacuula server. Сама по себе прошивка не даёт нового функционала
   (это переустановка того же ПО), но: (а) полезна как «золотой образ» для восстановления кирпича;
   (б) как артефакт для анализа контейнера `.swu` (структура, признаки подписи) — если понадобится
   аппаратный вектор (`serial-hardware-vector.md`).
3. **403 сейчас — дополнительное доказательство**, что вся неофициальная инфраструктура Neato деградирует,
   не только API облака. Усиливает приоритет vacuula server как единственного активно поддерживаемого пути.
